# Role art

Drop one image per role here, named `{role}.png` (lowercase, matching
`Role.value`):

```
werewolf.png  minion.png  seer.png  robber.png
troublemaker.png  drunk.png  insomniac.png  villager.png
card_back.png   # optional, for face-down cards
```

Until a PNG exists, the front-end falls back to a CSS card with the role emoji
(see `ROLE_EMOJI` in `../../app.js`), so the game is fully playable without art.

Do **not** commit copyrighted official ONUW artwork — use original or
AI-generated illustrations you have the rights to.
